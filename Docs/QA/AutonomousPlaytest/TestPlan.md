# Execution strategy

Baseline: branch `codex/unified-effect-director`, HEAD `587d78bcc5cb5b43d639b3b1b2605cff24af742a`, dirty working tree captured in Evidence/initial-git-status.txt and initial-tracked.patch. Product version 1.0 is not a unique build identifier. Old 2026-10-13 build path is absent; Editor execution tests the current compiled working tree once reload completes. Existing reports refer to earlier baselines.

Read ManualQA, EdgeCaseMatrix, EdgeCaseInventory, BugReports, RegressionReport and PlaytestRound3-2026-10-12. Runtime owners: SceneFlowController transitions, CabinStationView input/focus, ExpeditionLoop timeline/Journal/day-start, ExpeditionSaveStore atomic version-5 files, PhotoCaptureService candidate/SEND/archive, ZoneMissionRuntime prerequisites/rewards, capture minigame, ZoneNavigation and authored map gates. Existing temporary-save NUnit fixtures remain useful diagnosis, not completion evidence.

Mode A: start isolated New Game from Bootstrap; follow visible tutorial, map, mission and computer information. Use screenshots and player controls only. Attempt normal ending. Capture each milestone and suspected block. No mission APIs, teleportation, save editing, hidden spawn/objective lookup or debug presets.

Mode B begins explicitly after Mode A. Inspect failed interaction/state and logs; use isolated debug checkpoints only when useful. Any checkpoint-provisioned progress is labelled and excluded from completion claims. For confirmed P0/P1 defects, preserve a failing reproduction, make a focused fix, run a meaningful regression and replay original input.

Every input is timestamped, normalized to screenshot coordinates, limited to 15 seconds and automatically released. After each action inspect a fresh capture. A failed interaction gets at most three attempts with fresh observations; attempt ordinary recovery (close/reopen, pause/resume, Continue) before classifying a game block. A stable image alone is not a softlock: verify an expected meaningful change and distinguish disabled controls, focus, resource and driver failures. Stop a scenario after 120 seconds without meaningful progress or 3 failed recoveries; retain evidence and continue diagnosis. Long sailing is segmented into bounded holds and observations; avoid spending days while thinking by closing the helm.

Priority scenario families: tutorial and first PHOTO/SEND/CAPTURE; unsent PHOTO prerequisite; repeated SEND/rewards; Save/Continue; Rest and Journal replay; pause and minigame interruption; focus loss; resources/death; zone pairs forward/backward; rollback terrain/route persistence; resolution changes; final zone, choice and ending. Actual statuses belong in PlaytestReport, including BLOCKED and NOT RUN. Prior NUnit results are never imported as this run's PASS.
