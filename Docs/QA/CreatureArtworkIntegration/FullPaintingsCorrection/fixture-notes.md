# Native full-painting validation fixture

`Assets/_Project/Tests/PlayMode/FullPaintingPhotoIntegrationTests.cs` is a controlled visual fixture, not an ordinary-input voyage. Root alone operates Unity. Run `ZoneTwoExperiencePlaytestTools.SetupIsolation` in Edit Mode before launching either PlayMode case; the fixture requires that outer save/archive isolation and adds a temporary inner timeline/archive. Cleanup lets scene owners finish saving before restoring the outer overrides.

First run `ZoneTwoPrototypeFullPaintingReachesRealLabSendAndContinueWithoutRepainting`. Inspect the actual exported source, the `Z2_Creature_01-baked.png` generated by the shutter and the real Photo Lab screenshot in `native-validation/Prototype`. Bind the remaining paintings only after that review.

Then run `AllElevenFullPaintingsKeepSourcePixelsThroughPhotoLabGallerySendAndContinue`. It traverses all existing photo objectives, including both hidden Zone04 sites; it does not create IDs. It uses controlled contact positions/refills and the existing capture Win helper for the six mandatory photo/capture prerequisites. Capture artwork remains the separate cutout. Zone04 continues through the existing dialogue callback before opening Lab or inspecting hidden sites.

For each photo the evidence records exact dimensions and SHA-256 hashes for the source PNG, imported source RGBA pixels, newly baked photo, loose archive PNG, pending Continue, manually submitted durable snapshot and submitted Continue. Native source pixels and captured pixels must match exactly. PNG encoders may choose RGB or RGBA representation after a reload, so snapshot pixel equality is authoritative; the original loose archive must remain byte-identical. Source texture references must not be retained as the photograph's live image.

The actual Lab is checked for its selected photo ID, image reference, aspect ratio and manual SEND callback. Previous/Next selection is exercised where a previous record is available. SEND must grant only the matching objective once, and cannot rewrite the saved PNG. A verified pre-integration historical photo and metadata pair is copied into isolated storage and checked after loose loading and Save/Continue; source pixels and identity remain unchanged.

Gameplay measurement comparisons use the fixed-clock frame composer for Zones01–02 and a real calibration shutter with the complete painting temporarily disabled for Zones03–04. The calibration uses the original authored footprint and is deleted before gallery inspection. Temporary catalog changes are restored in `finally` without saving assets. Coverage, occlusion and the actual Z3/Z4 classification must stay equal; no threshold or ship-resource change is part of this fixture.

All outputs are new under `FullPaintingsCorrection/native-validation/Prototype` and `AllPaintings`. Older integration and horror-cycle evidence is untouched. Compilation, test pass and hash equality support correctness but do not replace root's visual review of every source/PNG/new photo/Lab image. This file describes the fixture and does not claim it has run.
